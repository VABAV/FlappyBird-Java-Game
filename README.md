# 🐤 FlappyBird – Java Game

🎮 A simple 2D clone of Flappy Bird built using Java. Features collision detection, score tracking, and real-time animation.

---

## 💻 Tech Stack
- Java (Core)
- BufferedImage, Timers

---

## ✨ Features
- Gravity physics and jumping
- Obstacle generation
- Live scoring
- Sound effects (optional)
